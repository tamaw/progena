# Final Check Skill

Before you finish a build:

- confirm the work you performed still matches the planned task metadata;
- confirm validation ran and summarize the outcome;
- if changes were committed, confirm a pull request URL exists;
- confirm the task worktree cleanup ran or call out the cleanup failure;
- call out any mismatches rather than hiding them.
