## 8. Status Protocol (STDOUT — REQUIRED)

The agent **MUST emit status lines** exactly in this format:

```
STATUS:{state}:{message}
```

### Required Emissions

| Lifecycle Event | Status Line |
|-----------------|------------|
Startup | `STATUS:starting:Initializing Hello World Agent` |
Server ready | `STATUS:running:Server started on port {port}` |
Request received | `STATUS:executing:Processing request` |
After response | `STATUS:waiting:Idle, waiting for requests` |
Fatal error | `STATUS:failed:{error message}` |
Shutdown start | `STATUS:stopping:Shutting down` |
Shutdown complete | `STATUS:stopped:Agent terminated` |
